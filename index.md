# tbepreport

R package for compiling and visualizing an integrated ecosystem health
report card for Tampa Bay.

## Installation

Install the development version from
[GitHub](https://github.com/tbep-tech/tbepreport):

``` r

# install.packages("remotes")
remotes::install_github("tbep-tech/tbepreport")

library(tbepreport)
```
